# Руководство пользователя

## Запуск приложения

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```
   python run.py
   ```
3. Откройте в браузере: http://127.0.0.1:5000

## Как пользоваться трекером

### Добавить новую привычку

1. Нажмите кнопку **«+ Новая привычка»** в верхнем меню.
2. Заполните поля:
   - **Название** — обязательное поле (например, "Пить воду").
   - **Описание** — необязательное, можно оставить пустым.
   - **Целевое количество раз в день** — например, 8 (раз пить воду
     в течение дня) или 1 (например, для привычки "Читать книгу").
3. Нажмите **«Сохранить»**.

### Отметить выполнение

На главной странице или на детальной странице привычки нажмите кнопку
**«✓ Отметить выполнение»**. Прогресс-бар обновится автоматически. Если
целевое количество на сегодня уже достигнуто, появится уведомление об
этом.

### Посмотреть историю

Откройте привычку (нажав на её название), чтобы увидеть таблицу с
историей выполнения за последние 7 дней — зелёная галочка означает, что
в этот день привычка была выполнена хотя бы один раз.

### Найти привычку

Введите часть названия в поле поиска на главной странице и нажмите
**«Найти»**. Список отфильтруется по совпадению в названии.

### Редактировать или удалить привычку

На детальной странице привычки используйте кнопки **«Редактировать»**
или **«Удалить»** в правом верхнем углу.

