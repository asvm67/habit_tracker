# Требования к проекту «Трекер привычек»

## 1. Проблема

Многим людям трудно выработать новую полезную привычку (пить достаточно
воды, читать каждый день, делать зарядку и т.д.), потому что нет простого
способа увидеть свой прогресс и не забыть отметить выполнение. Бумажные
чек-листы легко потерять, а сложные приложения с кучей лишних функций
отвлекают от главного. Нужен простой инструмент, который:

- позволяет завести привычку за 10 секунд;
- наглядно показывает, выполнена ли она сегодня;
- хранит историю за последние дни, чтобы видеть регулярность.

## 2. Целевая аудиория

- Студенты и работающие люди, которые хотят выработать полезные привычки
  (спорт, чтение, питьё воды, медитация и т.п.).
- Люди, которым не нужен сложный функционал (соцсети, уведомления,
  геймификация), а нужен простой и быстрый трекер.
- Любой пользователь с базовыми навыками работы с браузером — интерфейс
  максимально простой и понятный.

## 3. Функциональные требования

1. Пользователь может добавить новую привычку с названием, описанием и
   целевым количеством выполнений в день.
2. Пользователь может отметить выполнение привычки за текущий день одной
   кнопкой (можно несколько раз в день, если цель больше 1).
3. Пользователь может просмотреть список всех привычек с индикатором
   прогресса за сегодня (прогресс-бар и счётчик «N из M»).
4. Пользователь может открыть детальную страницу привычки и увидеть
   историю выполнения за последние 7 дней.
5. Пользователь может редактировать и удалять существующие привычки.
6. Пользователь может искать привычки по названию (поиск по подстроке).

## 4. Архитектура (схема)

```
 ┌────────────┐        HTTP-запросы (GET/POST)        ┌──────────────────┐
 │  Браузер   │ ───────────────────────────────────▶ │  Flask-сервер     │
 │ (клиент)   │ ◀─────────────────────────────────── │  (app/routes.py)  │
 └────────────┘        HTML-страницы (Jinja2)          └─────────┬────────┘
                                                                  │
                                                          SQL-запросы
                                                                  │
                                                         ┌────────▼─────────┐
                                                         │  SQLite (БД)     │
                                                         │  habits, logs    │
                                                         └──────────────────┘
```

### Основные маршруты

| Маршрут                       | Метод     | Функция            | Назначение                          |
|--------------------------------|-----------|---------------------|--------------------------------------|
| `/`                            | GET       | `index`             | список привычек + поиск             |
| `/habit/new`                   | GET, POST | `new_habit`         | форма добавления привычки           |
| `/habit/<id>`                  | GET       | `habit_detail`      | детальная страница + история        |
| `/habit/<id>/edit`             | GET, POST | `edit_habit`        | редактирование привычки             |
| `/habit/<id>/delete`           | POST      | `delete_habit`      | удаление привычки                   |
| `/habit/<id>/log`               | POST      | `log_habit`         | отметка выполнения за сегодня       |

### Таблицы БД

- **habits**: id, name, description, target_count, created_at
- **logs**: id, habit_id (FK → habits), log_date — одна запись = одна
  отметка о выполнении в конкретный день (несколько записей в день
  допустимы, если target_count > 1)
