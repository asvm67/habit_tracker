# 📈 Трекер привычек

Простое веб-приложение на Flask для отслеживания ежедневных привычек.
Пользователь добавляет привычки, отмечает их выполнение каждый день и
видит свой прогресс за последнюю неделю.

Учебный проект по дисциплине «Технологии разработки ПО»
(самостоятельная работа «Свой мини-проект: от идеи до работающего
прототипа», тема 1 — Трекер привычек).

## Возможности

- ➕ Добавление привычки (название, описание, целевое количество раз в день)
- ✅ Отметка о выполнении за текущий день
- 📊 Прогресс-бар выполнения за сегодня
- 📅 История за последние 7 дней
- 🔍 Поиск привычек по названию
- ✏️ Редактирование и 🗑️ удаление привычек

## Технологии

- Python 3 + Flask
- SQLite (через встроенный модуль `sqlite3`)
- Jinja2 (шаблоны)
- Bootstrap 5 (оформление)
- pytest (тестирование)

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <ссылка на репозиторий>
cd habit-tracker

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить приложение
python run.py
```

Приложение будет доступно по адресу: http://127.0.0.1:5000

## Запуск тестов

```bash
pytest -v
```

Тесты проверяют:
- работоспособность главной страницы (код 200);
- добавление привычки в базу данных;
- корректность поиска/фильтрации;
- обработку ошибки 404 для несуществующей привычки;
- работу функций валидации входных данных.
